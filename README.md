# Osso Export Classifier: published site and benchmark

This repository holds what is published of the Osso Export Classifier, live at
[osso.global](https://osso.global/): the web page, and the benchmark that measures it.
The classifier's code is proprietary and is not published.

- [The benchmark](benchmark/benchmark.md): the method, every case with its expected
  answer, and every run.
- [Known failures](benchmark/known-failures.md): every miss and what was done about it.
- [Threshold tables](benchmark/tables.md): the families where code, not the AI, decides,
  with an example question and case for each.

The classifier describes how a product reads against Annex I of Regulation (EU) 2021/821.
It is not legal advice, and every result must be reviewed by a qualified professional
before use.

The files here are published automatically from the private code repository; changes
made directly here are overwritten.
