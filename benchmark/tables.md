# Threshold tables

Where a table covers an entry, the AI only names the candidate provisions. The page then asks the exact threshold as a button question, and code checks the answer against limits copied word for word from the regulation. Entries with no table go through the AI interview. Every result must be reviewed by a qualified professional before use.
